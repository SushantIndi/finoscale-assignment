<h2>✨ Overview</h2>

<p>
This project is a frontend implementation of a financial statement dashboard.  
It replicates the given UI and allows users to dynamically add financial data for a new year.
</p>

<ul>
  <li>📊 Tabular display of financial data</li>
  <li>📅 Multi-year comparison</li>
  <li>➕ Add latest year financials dynamically</li>
  <li>⚡ Clean and responsive UI</li>
</ul>

<hr>

<h2>🚀 Features</h2>

<ul>
  <li>✅ Structured financial table with proper grouping (Assets)</li>
  <li>✅ Dynamic column addition for <b>31 MAR 2025</b></li>
  <li>✅ Modal popup form for data entry</li>
  <li>✅ Automatic calculation of totals</li>
  <li>✅ Horizontal scrolling for multi-year data</li>
  <li>✅ Sticky headers and first column</li>
  <li>✅ Clean component-based architecture</li>
  <li>✅ Basic input validation</li>
</ul>

<hr>

<h2>🛠 Tech Stack</h2>

<ul>
  <li>⚛️ React (Vite)</li>
  <li>🎨 CSS (Custom styling)</li>
  <li>🎯 Material Symbols & React Icons</li>
</ul>
